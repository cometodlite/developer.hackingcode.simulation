    MANUAL설명서
    재화

    · 크레딧: 기본 화폐. 상점 구매·코드 강화에 사용.

    · TOKEN: EVENT 기능 재화. OPS SHOP에서 사용.

    · COIN: 희귀 시즌 재화. SEASON SHOP에서 사용.

    · OneDay: ZERO-DAY 성장 재화. DISCOVERY 클리어와 시즌 보상으로 획득.

    · 취약점: ZERO-DAY 입장권. 스캔 1% 확률 / 조각 50개 제작.

    모드

    · NORMAL: 기본 해킹. 패널티 없음.

    · RISK: 성공률 -15%p, 보상 ×2. 실패 시 에너지 +1 소모.

    · EXTREME: Lv.5+, 성공률 -35%p, 보상 ×3. 실패 시 에너지 +2 소모.

    서버 루트

    · 외부 루트: 레벨 요구 -1, 보안 ×0.85, 보상 ×0.8.

    · 내부 루트: 기본 설정.

    · 코어 루트: 레벨 요구 +2, 보안 ×1.2, 보상 ×1.35.

    데이터 타워

    · 100층, 10챕터 × 10층 구조. 에너지 1 소모.

    · BREACH / SHIELD / FOCUS / EXIT 4액션 턴제 전투.

    · 첫 클리어 보상 > 반복 보상(80% 감소). 챕터 클리어 보상 별도.

    CAMPAIGN

    · CAMPAIGN은 선형 챌린지입니다. 다음 미클리어 노드만 새로 열립니다.

    · 데이터 타워와 달리 반복 보상 루프보다 첫 돌파와 순차 해금에 초점을 둡니다.

    · 추천 레벨과 추천 파워를 맞추면 성공률이 안정적으로 올라갑니다.

    EVENT / PASS

    · WEEKLY CHALLENGE: 매주 월 05:00 KST 리셋. SCORE·TOKEN 획득. 모든 목표 달성 시 보너스 보상 수령 가능.

    · 특별 출석: 누적 접속으로 매일 보상 수령.

    · PASS (헤더 버튼): 월간 시즌제. 패스 포인트 100 = 티어 1 상승 (최대 30티어). 미수령 티어는 PASS 버튼이 빛납니다.

    · 시즌 1: 2026-05-01 시작, 테마 ZERO-DAY.

    EXTEND 패널 / FLOW 분류

    · EXTEND는 CAMPAIGN, ZERO-DAY DISCOVERY, 특수전을 한 곳에서 관리하는 확장 패널입니다.

    · CAMPAIGN은 선형 챌린지, ZERO-DAY는 짧고 강한 DISCOVERY 런, 특수전은 제한 규칙이 걸린 단기 작전입니다.

    · INVENTORY와 SHOP에 붙는 보조 분류는 FLOW로 표시되며, 어떤 플레이 루프를 돕는지 빠르게 알려줍니다.

    · FLOW · Growth: 코드 성장, FLOW · Network: 스캔/해킹, FLOW · Tower: 타워, FLOW · Discovery: ZERO-DAY.

    ZERO-DAY DISCOVERY 플레이 방법

    · 준비: 취약점 1개가 필요합니다. 코드 스캔 1% 확률 또는 취약점 조각 50개로 제작합니다. 조각은 스캔/COIN 상점/시즌 보상으로 획득합니다.

    · 진입: LAB 패널 → ZERO-DAY 탭 → 온보딩 완료 → DISCOVERY 버튼. 난이도(PVE 입문/보통/어려움/혼돈)를 선택하고 시작합니다.

    · 런 진행: 단계별로 명령어를 입력해 목표 패치율을 높입니다. 각 단계에서 발각율이 누적되며 0%에 도달하면 실패합니다.

    · 명령어 단계: ① 정찰: scan/probe/enum → ② 침투: breach/inject/elevate/bypass → ③ 은폐: mask/cloak/wipe/scrub → ④ 교란: spoof/reroute/jam/decoy → ⑤ 탈출: exfil/exit/disconnect.

    · TRACE 앰플: 발각율을 낮춥니다. NULL 시드: 취약점 패치율을 낮춥니다. 둘 다 ITEMS에서 사용합니다.

    · 보상: OneDay, 취약점 조각, 크레딧. 입문 난이도는 하루 1회 무료, 이후 취약점 소모.

    · 현재 버전: PVE(싱글) 모드만 운영 중. PVP·경쟁 모드는 추후 추가됩니다.
